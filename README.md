# Deepwild

A first-person voxel survival sandbox for desktop browsers. You explore an endless procedural world, mine and build block by block, craft tools and armor, farm, fight, trade, wire up automation, and work through two extra dimensions to the final boss. Worlds persist in the browser.

Every texture, creature, sound, name and line of text in Deepwild is original and generated by its own code. There are no external art or audio files.

## Running it

Requirements: Node.js 18 or newer, and a desktop browser with WebGL 2 (current Chrome, Edge or Firefox on Windows, macOS or Linux).

```bash
npm install
```

```bash
npm run dev
```

Open the printed address (usually http://localhost:5173), click **Play**, then **Create new world**.

Other scripts:

| Command | What it does |
|---|---|
| `npm run build` | Type-checks, then writes a static site to `dist/` |
| `npm run build:single` | Writes one self-contained HTML file to `dist-single/index.html` (workers and code inlined) |
| `npm run preview` | Serves the `dist/` build locally |
| `npm test` | Runs the unit tests (world generation, meshing, winding, textures, crafting) |
| `npm run typecheck` | TypeScript only |

## Deploying

`npm run build` produces a fully static site in `dist/`. It uses relative paths, so any static host works:

- **Netlify / Cloudflare Pages / Vercel:** set the build command to `npm run build` and the output directory to `dist`.
- **GitHub Pages:** push `dist/` to a `gh-pages` branch, or use a Pages workflow that runs `npm ci && npm run build` and uploads `dist`.
- **Any web server:** copy the contents of `dist/` to the server's web root.

There is no backend. Saves live in each player's browser (IndexedDB), so clearing site data deletes worlds; use **Export** in the world list to keep a backup file.

## What's in the game

**World.** It's practically infinite and deterministic per seed, in 16×16×128 chunks generated and meshed in Web Workers. There are 18 biomes chosen from temperature, humidity, continentalness, erosion and ridge noise: grassland, oakwood, silverbirch grove, pinefrost woods, tundra, dunes, savanna, teak jungle, mirefen swamp, highcrags mountains, rustlands badlands, sporefields, bloommeadow, shoreline, river, ocean, deep ocean and frozen ocean. The terrain also has rivers, lakes, lava pools, floating islets, spaghetti tunnels, large caverns, underground lakes and a darkstone layer. Ores spread by depth (coal, copper, iron, gold, pulsite, azurite, diamond, verdite, starmetal), and there are six tree species, giant mushrooms, cacti, reeds, vines, flowers and berry bushes.

**Structures.** Villages with Wayfolk, farms, a smithy and a library; abandoned cottages; watchtowers; shipwrecks; buried caches; desert temples with a trapped vault; jungle shrines; dungeons with creature cages; mineshaft networks; and starfall craters. Emberdeep has Ember Bastions, and The Hollow has its arena and outer spires. Chests use loot tables, and some loot is enchanted.

**Blocks.** 191 data-driven blocks (179 placeable) and 340 item types in total. Each has hardness, a preferred tool, a tool-tier requirement, drops, transparency, collision, a placement rule, light emission and a sound. Shapes include cubes, plants, liquids and multi-box models: stairs, slabs, fences, gates, walls, panes, doors, trapdoors, ladders, torches, levers, buttons, plates, rails, signs, beds and pistons.

**Survival.** Health, hunger, saturation and exhaustion; natural regeneration; starvation; fall, fire, lava, drowning, suffocation and contact damage; armor and toughness; status effects; XP and levels; death drops; and respawning at your bed or the world spawn. Difficulty runs from Peaceful to Hard.

**Crafting.** About 200 recipes with 2×2 and 3×3 grids, shaped (mirrorable) and shapeless, using tag ingredients such as "any planks". A searchable recipe book has categories and a craftable filter, and click-to-fill.

**Equipment.** Seven tool tiers (wood, stone, copper, iron, gold, diamond, cinderite) with durability, mining speed, damage and attack cooldown. Armor comes in six materials with four pieces each. There are bows and arrows, shields, shears, fishing rods, buckets, a flint striker, saddles, leads, boats and rail carts. The endgame Starforged Blade and Sovereign Halo come from the final boss.

**Machines.** Furnace, smokehouse and blast furnace (fuel and cook times), chests, the runic altar for enchanting (14 enchantments, levels plus azurite, bookshelf power), the anvil (repair and combine), the brewing stand (10 brews), dispensers and hoppers.

**Pulse automation.** Wire with signal falloff (15 down to 1), levers, buttons, pressure plates, inverting pulse torches, repeaters (1–4 tick delay), comparators (compare or subtract, and they read container fullness), lamps, pistons and sticky pistons, dispensers, hoppers that lock when powered, doors, trapdoors and powder kegs.

**Farming and food.** Tilled farmland that is hydrated by water or rain, and wheat, carrots, potatoes, beets, sunberries, melons, pumpkins and reeds. Crops grow in stages, and bone meal speeds them up. Cooking, fishing (fish, junk and treasure), milk and stews round it out.

**Creatures.** All are original designs.
- Passive: grazer, fluffer (shearable, dyeable), snoutling, cluckit (lays eggs), steed (tame, saddle, ride), burrowkin, finling, frostfox, miretoad and sporeback.
- Hostile: shambler (burns in daylight), fusebloom (swells and bursts), rattler (archer), skitterfang (climbs walls), Gravemaw brute, cave wisp, hexwarden (elite caster), cinder imp, ashen knight, emberling and voidstalker (blinks).
- Villagers: Wayfolk with seven professions, homes, day and night routines, trades priced by reputation, and Stoneward guardians.
- AI includes A* pathfinding, flee, tempt, breed, melee, ranged, flying, casting and fuse behaviour, with spawning by light, biome, depth, time and difficulty.

**Villages.** Reputation, restocking trades, and night sieges that you can break for the Hero discount.

**Weather.** A day/night cycle with sun, moon and stars, drifting clouds, rain, snow, thunderstorms with lightning, and sleeping in beds.

**Dimensions and bosses.**
1. Build an **Ember Rift Core** and set it in a ring of eight obsidian, then strike it with a Flint Striker. Stand on the rift for 2.5 s to reach **Emberdeep**, a volcanic realm with lava seas, basalt deltas, ash wastes, lumen clusters, cinderite, flarequartz and Ember Bastions.
2. Defeat the **Magma Colossus** on a bastion throne. It has a slam, fireball volleys and emberling summons, and it drops the **Ember Core**.
3. Craft a **Hollow Rift Core** from Ember Cores, Starmetal Shards and a Rift Core. In **The Hollow**, break the four **Ward Pylons** to drop the **Shard Sovereign's** shield, then defeat it. It fires homing shards, dives at you and summons voidstalkers. A Homeward Gate then opens, and its heart forges the endgame gear.

**Creative mode.** Unlimited items with a searchable catalogue, flight, instant breaking and no damage. It has time, weather and spawning controls, a mode switch, and a Builder's Wand for fills and clears of up to 65,536 blocks.

**Worlds.** Multiple save slots, a name and seed, mode, difficulty, starting items (none, a basic kit or a bonus chest), and eight world rules. You can duplicate a world (backup), export or import it as JSON, and delete it after confirming. It autosaves only the chunks that changed, plus player and world state, every 20–30 s, on quit and on page hide. Unreadable records are skipped with a warning instead of wiping the world.

**Settings.** Render distance (2–16), simulation distance, FOV, render scale, frame-rate cap, particles, creature render distance, smooth shading, texture filtering, anti-aliasing, clouds, creature shadows, view bobbing, interface scale, FPS display, sensitivity, invert Y, key bindings, and master, music, effects and ambience volume with mute.

## Architecture

```
src/
  game/
    registry/     blocks, items, recipes, enchantments: pure data shared with workers
    world/
      gen/        terrain + biomes, structures, per-dimension chunk generators
      mesher.ts   light flood-fill + greedy meshing (runs in workers)
      World.ts    chunk store, streaming, block get/set, scheduled ticks, mesh upload
    workers/      gen.worker.ts, mesh.worker.ts
    entity/       physics (swept AABB), creature models, AI, items, projectiles, vehicles
    player/       controller + survival stats, inventory
    systems/      fluids, pulse automation
    gfx/          procedural textures, terrain shader, sky, particles
    audio/        WebAudio synthesizer
    save/db.ts    IndexedDB: worlds, changed chunks, world state, export/import
    Game.ts       loop (render per frame, simulation at 20 ticks/s), rules, dimensions, saving
    interact.ts   mining, placing, item use, combat, riding
    spawning.ts   creature spawning, cages, sieges
  ui/             React screens, HUD, inventory (Zustand store; no per-frame React renders)
```

Rendering details:

- Chunks are meshed off the main thread. Light is computed by flood fill over a 3×3 chunk neighbourhood, so torchlight and skylight cross chunk borders.
- Full cubes use greedy meshing: faces merge when the texture, light and ambient occlusion match.
- Each chunk has three render layers: opaque, alpha-cutout and translucent.
- Textures live in a texture array with mipmaps, and merged quads repeat their texture per block.
- Only modified chunks are written to IndexedDB. Unmodified terrain is regenerated from the seed.

## Multiplayer

**Multiplayer is not included.** There is no host or join button, because a browser-only game has no way to relay players to each other without a server. The single-player architecture is set up so it can be added:

- All world mutations go through `World.set`, and gameplay state lives outside the renderer, so block changes can be serialized as small `(dim, x, y, z, id, meta)` messages.
- Generation is deterministic from the seed, so clients only need the seed plus changed chunks, the same records the save system already produces.
- Entities already serialize and restore through `EntityManager.restore`.

A real implementation would need a small authoritative server (for example Node.js with WebSockets) that runs `World`, the simulation and the entity tick headlessly, owns the save data, and streams chunk records, block deltas, entity snapshots and chat to clients. Peer-to-peer WebRTC would also need a signalling server.

## Known limits

- The world is 128 blocks tall.
- Light changes re-mesh the edited chunk and its neighbours; on slower machines that can take a frame or two to appear.
- Shadows are soft drop-shadows under creatures, not real-time cast shadows on terrain.
- Rail carts follow straight rails and simple corners. There are no powered rails or junction switching.
- The anvil repairs and combines, but it cannot rename items.
